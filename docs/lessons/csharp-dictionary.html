1. Dictionary 是什麼：用 key 找 value

List 是「第幾個」找東西，Dictionary 是「用名字」找東西。每一筆是一對：key（用來找的）與 value（找到的內容）。

var price = new Dictionary<string, int>      // key 是 string，value 是 int
{
    ["可樂"] = 30,
    ["綠茶"] = 25,
    ["咖啡"] = 60,
};

Console.WriteLine(price["可樂"]);               // 30
Console.WriteLine(price.Count);                 // 3
Console.WriteLine(price.ContainsKey("咖啡"));   // True
Console.WriteLine(price.ContainsKey("牛奶"));   // False
List<T>Dictionary<TKey, TValue>
怎麼找位置：list[0]key：price["可樂"]
找的速度要找特定內容得一個一個看直接跳到那個 key，資料再多也一樣快
能不能重複內容可以重複key 不能重複，value 可以
適合一串有順序的東西對照表、用編號或名稱查資料

Dictionary<string, int> 尖括號裡第一個是 key 的型別，第二個是 value 的型別。key 常見的是 string、int、enum。

2. key 不存在時：三種讀法

Console.WriteLine(price["牛奶"]);
// KeyNotFoundException: The given key '牛奶' was not present in the dictionary.

if (price.TryGetValue("牛奶", out var p))     // 回傳 False，p 是 0
{
    Console.WriteLine(p);
}

Console.WriteLine(price.GetValueOrDefault("牛奶"));       // 0
Console.WriteLine(price.GetValueOrDefault("牛奶", -1));   // -1
寫法key 不存在時什麼時候用
price[key]丟 KeyNotFoundException確定一定有；沒有就代表程式有錯
price.TryGetValue(key, out var p)回傳 false，p 是 value 型別的 default不確定有沒有，而且兩種情況要分開處理
price.GetValueOrDefault(key, 預設值)回傳預設值沒有就用預設值，不用分開處理

out var p：這個方法有兩個結果要給你，「有沒有找到」用回傳值，「找到的內容」放進 p。找不到時 p 是 default（上一頁），所以要先看回傳值再用 p。

不要寫成先 ContainsKey 再 price[key]：那樣會找兩次，TryGetValue 一次就完成。

3. 新增、修改、移除

price["牛奶"] = 40;            // 沒有這個 key → 新增。Count 變成 4
price["可樂"] = 35;            // 已經有這個 key → 改掉 value。Count 還是 4

price.Add("可樂", 99);
// ArgumentException: An item with the same key has already been added. Key: 可樂

Console.WriteLine(price.TryAdd("可樂", 99));   // False，可樂還是 35
Console.WriteLine(price.Remove("牛奶"));       // True，Count 變回 3
寫法key 已經存在時key 不存在時
price[key] = 值覆蓋新增
price.Add(key, 值)丟 ArgumentException新增
price.TryAdd(key, 值)不動，回傳 false新增，回傳 true

想要「有就改、沒有就加」用 [key] = 值；想要「重複就是錯誤，要立刻知道」用 Add。

4. 逐筆走過：pair.Key 與 pair.Value

foreach (var pair in price)
{
    Console.WriteLine($"pair.Key = {pair.Key}, pair.Value = {pair.Value}");
}

foreach (var (name, amount) in price)      // 直接拆成兩個變數
{
    Console.WriteLine($"{name}：{amount}");
}

Console.WriteLine(string.Join(", ", price.Keys));     // 可樂, 綠茶, 咖啡
Console.WriteLine(string.Join(", ", price.Values));   // 35, 25, 60
pair.Key = 可樂, pair.Value = 35
pair.Key = 綠茶, pair.Value = 25
pair.Key = 咖啡, pair.Value = 60
可樂：35
綠茶：25
咖啡：60
  • foreach 每一圈拿到的是「一對」，型別是 KeyValuePair<string, int>。pair 這個名字是自己取的，.Key 是左邊、.Value 是右邊
  • 之後在 LINQ 裡看到 pair => pair.Value，pair 就是這個東西
  • 不要依賴順序。這次印出來剛好是加入的順序，但 Dictionary 不保證。需要固定順序就自己排序：price.OrderBy(pair => pair.Key)

5. 用 LINQ 查：用 value 反過來找 key

Dictionary 天生只能「用 key 找 value」。想反過來「哪些 key 的 value 符合條件」，把它當成一串 pair 用 LINQ 過濾：

// 哪些商品超過 30 元
var expensive = price.Where(pair => pair.Value > 30).Select(pair => pair.Key);
Console.WriteLine(string.Join(", ", expensive));   // 可樂, 咖啡

// 對應表：左邊是資料庫裡的狀態，右邊是顯示給使用者的文字
var progress = new Dictionary<string, string>
{
    ["Pending"] = "進行中",
    ["Paid"] = "進行中",
    ["Shipped"] = "已完成",
    ["Cancelled"] = "已取消",
};

Console.WriteLine(progress["Paid"]);     // 進行中          ← 正方向：用 key 找 value

var keys = progress
    .Where(pair => pair.Value == "進行中")   // ① 只留下 value 是「進行中」的那幾對
    .Select(pair => pair.Key)                // ② 取出它們的 key
    .ToList();                               // ③ 收成清單
Console.WriteLine(string.Join(", ", keys));  // Pending, Paid   ← 反方向：用 value 找 key
方向寫法結果有幾個
key → valueprogress["Paid"]剛好一個（key 不重複）
value → key.Where(pair => pair.Value == …).Select(pair => pair.Key)零個、一個或多個（value 可以重複）
  • 反方向可能找到多個，所以結果是清單。找不到時是空清單，不會丟例外
  • 這裡的 .ToList() 只在記憶體裡跑，不連資料庫：它的主體是 progress（LINQ 實驗室 L4-07）
  • 這個「反查」的實際用途：使用者選的是顯示用的狀態，要先換成資料庫裡的狀態才能查。見 enum 那一頁第 7 節與 L4-12

6. 從清單做出 Dictionary

var products = new[] { new Product(1, "可樂", 30), new Product(2, "綠茶", 25), new Product(3, "咖啡", 60) };

var byId = products.ToDictionary(p => p.Id);                      // key 是 Id，value 是整個 Product
Console.WriteLine(byId[2].Name);                                  // 綠茶

var nameToPrice = products.ToDictionary(p => p.Name, p => p.Price);   // key 是名稱，value 只取價格
Console.WriteLine(nameToPrice["咖啡"]);                           // 60

record Product(int Id, string Name, int Price);

用途：要在迴圈裡反覆「用 Id 找商品」時，先轉成 Dictionary，之後每次查都是直接跳到那一筆，不用每次從頭找。

key 重複時 ToDictionary 會丟例外：

ArgumentException: An item with the same key has already been added. Key: 1

一個 key 要對應到多個東西時，先分組再轉，value 放清單：

var items = new[] { ("飲料", "可樂"), ("飲料", "綠茶"), ("零食", "餅乾") };

var groups = items
    .GroupBy(x => x.Item1)
    .ToDictionary(g => g.Key, g => g.Select(x => x.Item2).ToList());
// 飲料 → [可樂, 綠茶]
// 零食 → [餅乾]

7. key 怎麼算「相同」

var a = new Dictionary<string, int> { ["Cola"] = 1 };
Console.WriteLine(a.ContainsKey("cola"));    // False  ← 字串預設區分大小寫

var b = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase) { ["Cola"] = 1 };
Console.WriteLine(b.ContainsKey("cola"));    // True
  • 字串當 key 時預設區分大小寫。要不分大小寫，建立時傳 StringComparer.OrdinalIgnoreCase
  • int、enum 當 key 最單純，值一樣就是同一個 key
  • key 不能是 null；value 可以
  • Dictionary 和 JSON 的物件長得很像（都是「名字：值」），兩者可以互轉，見 JSON 那一頁第 6 節
